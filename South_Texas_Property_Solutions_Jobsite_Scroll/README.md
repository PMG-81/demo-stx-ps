# South Texas Property Solutions — Scroll Jobsite Demo

Concept site by Porter Media Group (unofficial). This demo uses an illustrative **three-stage photographic scroll sequence**, not a real time-lapse of the same property. The photos used in the hero are demonstration visuals; do not present them as actual business jobs.

## Deploy to GitHub + Vercel

Upload **the contents of this folder** (index.html, styles.css, script.js, assets/) into the GitHub repository root. In Vercel set Framework Preset to **Other**, Root Directory to **./** (or leave default), no build command, default output directory. Deploy.

## Customize with actual job footage

For a truly continuous beginning-to-end jobsite sequence, supply actual video or a matching fixed-camera series from one property. This demo currently fades between three illustrated stages in response to scrolling. Replace `assets/brush.jpg`, `assets/equipment.jpg`, and `assets/clearing.jpg` with licensed images or implement video scrubbing once footage is available.

Contact phone is from the supplied Facebook screenshot, and the inquiry form launches the visitor's SMS application, not a hosted backend. The logo is an approximation from the trailer.
